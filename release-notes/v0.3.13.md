Improves stable-channel freshness and the Updates page, and adds versioned release documentation.

- Fetch mutable stable metadata through the GitHub contents API, with immutable commit downloads and SHA-256 checks for application files.
- Use a single validated bootstrap manifest and refuse an older channel than the installer.
- Show operation progress, success/failure and timeouts automatically, with bounded requests and no full-page reload.
- Preserve local settings/history and retain the existing backup/recovery behavior. No automatic Pi reboot.
- Add CHANGELOG.md and automated tags/Releases for documented versions.

Existing 0.3.11 installations can rerun the one-time bootstrap from the immutable source link in the setup instructions to avoid an old cached launcher. A successful setup prints the actual installed version. Confirm the page reports 0.3.13 and Check now completes.

Validation: see the source test instructions. Offline tests do not replace a successful installation and RF reception on the device. The GitHub workflow token publishes notes/tags; the device follows the separate stable manifest.

One-time bootstrap for an existing device (immutable launcher):

```sh
curl --fail --location --max-time 60 https://raw.githubusercontent.com/johndball/pisonde-mobile/{{SOURCE_COMMIT}}/bootstrap-updates.sh -o /tmp/pisonde-updates.sh && sudo bash /tmp/pisonde-updates.sh
```
