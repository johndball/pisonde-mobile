# PiSonde Mobile 0.3.16

Fresh installs now verify the publisher signature, check application file hashes, create the configuration directory as root:root mode 0755, and enroll the public key during `install.sh`. New users continue with standard hardware/AP setup; no extra enrollment command is needed.

The installer fetches `updates/releases/0.3.16.json`, verifies it against the bundled pinned key, checks source bytes before copying and installed bytes before enrolling, and refuses existing configured devices/history or conflicting keys. Directory normalization preserves individual files' ownership. Hardware setup checks enrollment before changing Wi-Fi.

Already-enrolled devices can install through the GUI or their automatic update policy. Existing settings, Wi-Fi profiles and reception history remain intact. Unenrolled older devices still require one-time enrollment.

Validation: 194 offline regression checks, including real Ed25519/OpenSSL checks, directory ownership/permissions, symlink rejection, tampered/expired metadata, source/installed-file mismatches, and setup ordering. Full fresh-card installation on arm64/Trixie and RF reception need device-side verification.
