# PiSonde Mobile 0.3.15 — first signed application release

Signed-channel enrollment is required once per device. Existing 0.3.14 devices stay on the legacy channel until enrolled. Historical releases/tags are unchanged.

The updater verifies Ed25519 signatures against an independently enrolled public key, checks metadata validity and sequence, then checks commit-pinned source and file hashes before staging/applying. It has no unsigned fallback. The private signing key stays with the publisher, outside GitHub and receiving devices.

The original backup, service/API/database health checks and rollback behavior remain. A failed initial enrollment leaves the automatic-update timer stopped until the issue is resolved. Reception, saved Wi-Fi profiles and local history remain available with the previous application after a successful rollback.
