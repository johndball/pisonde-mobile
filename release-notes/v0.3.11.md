Historical updater introduction — superseded; use the current stable version.

Added scheduled checks, maintenance-window installation, dashboard controls, app/database backup, health checks and rollback recovery. No automatic Pi reboot; local settings and reception history are retained.

Known issue: one-time setup called the unsupported `Path.chown()` method and could stop before installing the application. Later versions correct this. Published as a historical prerelease rather than a recommended installation target.
