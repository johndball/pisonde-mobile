# PiSonde Mobile 0.3.14

Three independent update choices replace the fixed automatic-install setting:

- Scheduled installation in a selectable two-hour window, shown as 0300–0500, 0500–0700 and so on in Pi local time.
- Installation at the next reboot after a known update missed a selected window.
- Immediate installation when an update is detected, including Check now.

Any combination is allowed. Immediate mode takes priority; all off means manual installation only. Existing enabled settings remain scheduled 0300–0500, with the new behaviors off. Disabled settings remain disabled. Use **Save update settings** to apply selections.

Existing devices can install through Updates → Check now → Install now. The root broker migrates the updater timer once; no additional SSH bootstrap is required. GitHub checks stay about six-hourly, while policy is evaluated hourly and during startup. Settings, saved Wi-Fi profiles and reception history are preserved.

Validation: 150 offline regression checks, including policy combinations, midnight/local-time boundaries, boot eligibility/retries, legacy settings, CSRF/API controls, JavaScript syntax and existing rollback/integrity tests. Hardware scheduling and reboot behavior still need device-side verification.
