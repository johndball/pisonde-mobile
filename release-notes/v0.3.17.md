# PiSonde Mobile 0.3.17

Uploads now includes configurable history retention: keep forever (default), 30/60/90/180/365 days, or cleanup below a selected free-space threshold (10% default). Enabling deletion requires confirmation. Optional protection, enabled by default, preserves latest target positions and latest receptions for noted/recovery-marked targets. The newest reception is always retained; low-space cleanup protects the newest five minutes.

Cleanup removes eligible receptions and linked upload/validation payloads from the active database. Notes, existing backups and diagnostic logs are retained under their own policies. Export important CSV/GPX/weather-validation data first. Bounded maintenance runs at startup, about every five minutes and after saving. Low-space SQLite compaction requires working space and cannot reclaim unrelated files; age-mode deleted space is reused internally.

Device controls provide confirmed restart and shutdown through a narrow root broker. Restart/shutdown is delayed five seconds for a response; update/power interlocks reject conflicts. Wait for normal shutdown to complete before unplugging. The interface adds blue navigation, green save/resume, amber lock/restart and red shutdown actions.

Validation: 218 offline regression checks, including real SQLite cleanup/compaction and rollback, protected GPS history, CSRF and strict broker validation, update/power conflicts and simulated JavaScript interactions. No test reboots or shuts down the test host. Actual Pi power operations and browser appearance still require field checks.

Existing history is preserved on upgrade unless a retention policy is subsequently enabled. Install through the enrolled GUI or existing automatic-update policy.
