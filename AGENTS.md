# PiSonde Mobile repository scope

This repository contains software, tests, installation instructions, hardware documentation and license notices.

Keep nontechnical editorial materials, publication images and external publication placeholders outside this repository and outside software release archives. Do not add links or references to those materials in the application, operator documentation or installation instructions.

The receiver brand name `RTL-SDR Blog V4` is legitimate hardware terminology and must remain intact.

Before any code upload or release, run `run_tests.py`, including `test_release_contents.py`, and inspect the tracked-file list. Exclude runtime configuration, credentials, hardware identities, reception data and private media. Preserve upstream license notices.
